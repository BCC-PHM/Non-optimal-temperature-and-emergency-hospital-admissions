# Non-optimal ambient temperature and emergency hospital admissions in Birmingham: A quantitative analysis
This repository contains the R code and selected outputs from a quantitative analysis project that explored the association between non-optimal ambient temperatures and emergency hospital admissions in Birmingham (2015-2024).
## Repository structure
### Code
The `Code` folder contains the R scripts used throughout the analysis.
1. Loading packages and preparation
2. Creation of case time series and aggregated datasets
3. Linking exposure data
4. Descriptive statistics
5. Preliminary quasi-Poisson regression models (5a. All ages and 5b. Age sub-group analyses)
6. Distributed Lag Non-Linear Models (DLNMs) and interaction analyses
7. DLNM age-group analyses
8. Attributable risk estimates
Scripts are numbered to reflect the order in which they were run.
### Outputs
The `Outputs` folder contains selected figures and tables produced during the analysis.
## Data availability
The underlying datasets are subject to information governance and data-sharing restrictions and cannot be made publicly available. 
## Reproducibility
The code is provided to support transparency and reproducibility. Due to restrictions on access to the underlying datasets, users will not be able to fully reproduce the analysis.
